QNN_Raw_Data contains all the quantum neural network data collected before averaging or other data processing

QNN_Raw_Data_2 contains all the quantum neural network data data collected with the error for each individual sample

QNN_Plot_Data contains the quantum neural network data data using creating paper and presentation plots

CNN_Raw_Data contains all the classical neural network data collected before averaging or other data processing

CNN_Raw_Data_2 contains all the classical neural network data data collected with the error for each individual sample

CNN_Plot_Data contains the classical neural network data data using creating paper and presentation plots

Plots.m is the code used to create the plots for the presentation

Copy_of_Plots.m is the code used to create the paper plots
