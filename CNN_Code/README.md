
CNN_Training_NotSaved trains a neural network, 3 Layers, and prints the results for inspection

CNN_Training_Saved train the neural network with the parameters given by the input file CNN_Data.xlsx and records the absolute mean and absolute maximum error and time in the excel file

CNN_Training_Saved_All train the neural network with the parameters given by the input file CNN_Data_All.xlsx and records the absolute mean and absolute maximum error and time in the excel file as well as the absolute error for each sample.

All file use Surface_features.csv from reference 1
