
QNN_Training_NotSaved trains a neural network, 1-6 qubits, and prints the results for inspection

QNN_Training_Saved train the neural network with the parameters given by the input file QNN_Data.xlsx and records the absolute mean and absolute maximum error and time in the excel file

QNN_Training_Saved train the neural network with the parameters given by the input file QNN_Data_All.xlsx and records the absolute mean and absolute maximum error and time in the excel file as well as the absolute error for each sample.

All file use Surface_features.csv from reference 1
